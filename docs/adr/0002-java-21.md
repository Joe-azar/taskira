# ADR-0002 — Conserver Java 21 LTS

- Statut : Accepted
- Date : 2026-08-15

## Contexte

La baseline utilise Java 21, version LTS compatible avec Spring Boot actuel et la cible Spring Boot 4.

## Décision

Java 21 reste la version de compilation et d'exécution. La migration ne passe pas à Java 25. Le Maven wrapper et les images Docker constituent les environnements reproductibles.

## Conséquences

- Pas de changement de langage pendant les upgrades framework.
- Toute dépendance doit être compatible Java 21.
- Les développeurs ne dépendent pas d'un JDK global grâce à Docker.

## État d'implémentation

Java 21 est déjà configuré dans Maven et les images backend.
